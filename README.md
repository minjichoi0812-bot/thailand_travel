# 쭈내&밍이 태국 여행

2027.02.02–02.12 · 방콕·후아힌 · 10박 11일

자연 일러스트 디자인의 여행 일정·경비·준비물 플래너입니다.

## 기능

- 한국/방콕 항공 시각 전환, 출발 D-day, 2주 달력과 날짜별 일정
- 경비의 숙소명과 일정의 숙소 카드 연동
- 항목별 쭈내/밍이/공통 부담자 선택: 항공권은 쭈내, 숙소는 밍이, 나머지는 공통(반반)
- 단가·총액 직접 입력, 추가·삭제·되돌리기
- 준비물 체크, 브라우저 자동 저장, JSON 백업/불러오기

## 열기

GitHub Settings → Pages → Deploy from a branch → main / (root) → Save.

배포 후 주소: https://minjichoi0812-bot.github.io/thailand_travel/

## 파일 및 데이터

`index.html`, `style.css`, `app.js`, `assets/`는 최신 자연 일러스트 HTML을 웹 배포용으로 분리한 파일입니다. 기존 결혼 예산 저장소와 독립적으로 동작합니다.

입력한 데이터는 현재 브라우저에 저장되며 다른 기기로 자동 동기화되지 않습니다. 기존 HTML에서 입력한 데이터는 백업 저장 후 새 웹사이트에서 불러올 수 있습니다.

이 저장소는 공개되어 있어 기본 여행 일정과 초기 경비 금액이 공개됩니다. 예약번호, 항공권 원본, 여권 정보, 연락처는 포함하지 않습니다. `noindex`는 검색엔진 지침이며 접근 제한 기능은 아닙니다.
